# 即问 · Jiwen

录下课堂讲解，实时查看文字，选中听不懂的内容向 AI 提问。

支持中文和英文界面。录音、转写和对话按课堂保存，可回看和下载。

## 在自己的电脑使用

启动后直接进入课堂，无需注册。配置自己的转写和问答服务后，即可使用 AI 功能。源码免费，云端服务的费用由你承担。

录音、文字和对话保存在自己的电脑上，不会按期限自动删除。使用云端服务时，相应音频或文字会发送到你配置的服务。

需要 **Node.js 24 或更新版本**及其附带的 npm。Windows 可下载源码并解压，再双击 `启动.cmd`。其他系统或使用命令行时，安装 Git 后执行：

```sh
git clone https://github.com/MrRoam/jiwen.git
cd jiwen
npm ci
npm run dev
```

打开 [http://localhost:4317](http://localhost:4317)。点击侧栏底部「设置 → 转写与问答」，填写自己的服务密钥，保存后分别测试连接。密钥只填在自己的应用里。

录一段约 30 秒的音频，暂停并等待保存，确认转写、提问和回放可用。使用期间保持启动终端开启；按 Ctrl+C 停止应用。

不熟悉安装时，可按[本机使用与 AI 协助](docs/自行部署与AI协助.md)，让 AI 带你完成。

## 使用方式

点击「课堂转写」标题旁的下载图标，可导出当前课堂的 TXT 转写，包含时间戳；尚在识别的文字会标注状态。

1. 点击「开始录音」，允许浏览器使用麦克风。
2. 查看实时转写。输入问题，或选中文字后点击「就此提问」。
3. 老师提出问题时，点击「HELP」获取简短回答，再继续追问。
4. 点击「暂停录音」，等待保存完成，再回放。点击转写时间可跳到对应录音位置。
5. 打开「设置 → 我的资料」，下载录音和数据副本。

同一对话的追问沿用首次提问时的课堂内容。需要结合后面的讲解时，请新建对话。

录音时保持页面在前台。关闭页面或电脑休眠可能中断录音。转写失败时仍会保存录音，缺失文字是否能补齐，以页面状态为准。

恢复上传需要使用原设备和浏览器。尚有内容待上传时，请保留浏览器的网站数据。

## 在线体验

[打开即问体验站](https://jiwen.yaojiaxu.com)

体验站需要邮箱注册。目前免费，新账号有一次性 1 小时转写额度，用完不自动恢复；问答额度可在账号面板查看。站点课堂保存 30 天，请在到期前下载重要资料。体验站资料不会自动迁移到自己的电脑。

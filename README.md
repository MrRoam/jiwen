# 即问 · Jiwen

录下课堂讲解，实时查看文字，选中听不懂的内容向 AI 提问。

支持中文和英文界面。录音、转写和对话按课堂保存，可回看和下载。

## 在线体验

[打开即问](https://jiwen.yaojiaxu.com)

使用邮箱验证码和密码注册。体验站目前免费，每个新账号一次性获得 **1 小时转写**，用完不自动恢复。AI 问答有每日使用限制，可在侧栏底部的账号面板查看剩余额度。

转写额度用完后，仍可录音、回放和下载。已有文字仍可用于提问，问答受每日额度限制。

课堂从最后一次成功上传音频起保存 **30 天**，到期会删除。请在到期前打开「账号 → 数据与反馈」，下载录音和数据副本。

## 使用方式

1. 点击「开始录音」，允许浏览器使用麦克风。
2. 查看实时转写。输入问题，或选中文字后点击「就此提问」。
3. 老师提出问题时，点击「HELP」获取简短回答，再继续追问。
4. 点击「暂停录音」，等待保存完成，再回放。点击转写时间可跳到对应录音位置。

同一对话的追问沿用首次提问时的课堂内容。需要结合后面的讲解时，请新建对话。

录音时保持页面在前台。手机锁屏、来电、切换应用或关闭页面可能中断录音。

断网后，请保留原设备和浏览器的网站数据。重新联网后，用原账号打开页面并点击「恢复上传」。转写失败时仍会保存录音；缺失文字是否能补齐，以页面显示的状态为准。

## 快速开始

也可以在自己的电脑或服务器运行即问。源码免费；转写和问答服务的费用由你承担。新实例需要单独注册，体验站的账号和资料不会自动迁移。

不熟悉部署时，打开[自行部署与 AI 协助](docs/自行部署与AI协助.md)，复制其中的提示，让 AI 带你完成。

本机运行需要 Git、**Node.js 24 或更新版本**及其附带的 npm。

**1. 下载项目并创建配置。**

```sh
git clone https://github.com/MrRoam/jiwen.git
cd jiwen
npm ci
npm run setup
```

**2. 配置注册邮件。**

在项目根目录的 `.env` 填写邮件服务地址、端口、发信邮箱和授权码，对应 `SMTP_HOST`、`SMTP_PORT`、`SMTP_USER`、`SMTP_PASS`。具体步骤见[注册邮件配置](docs/自行部署与AI协助.md#配置注册邮件)。`npm run setup` 会保留已有配置。

**3. 启动应用。**

```sh
npm run dev
```

打开 [http://localhost:4317](http://localhost:4317)，点击「开始使用」，用邮箱验证码和密码注册。新实例的首个账号是管理员。使用期间保持启动终端开启；按 Ctrl+C 停止服务。

**4. 连接转写和问答服务。**

登录管理员账号，打开「侧栏底部账号 → API 配置」，填写自己的服务密钥，保存后分别测试连接。接口要求见 [API 配置说明](docs/API配置.md)。密钥只填在自己的实例里。

录一段约 30 秒的音频，暂停并等待保存。确认文字、提问和回放都可用后，再开始正式使用。

需要在手机或其他设备上使用时，按[服务器部署说明](deploy/README.md)配置 HTTPS。

# 即问 · Jiwen

课堂录音、实时转写与 AI 问答应用。录下讲解，选中原文提问，或用 HELP 快速回答老师刚刚的问题；录音、文字和对话保存在自己运行的服务器。

支持中文和英文界面、邮箱注册登录、课堂管理、录音回放、Markdown 与数学公式。个人电脑可直接运行，服务器可通过 Docker Compose 部署。

## 在线体验

本站仅供体验，当前不收费。验证邮箱并设置密码后，每个新账号一次性赠送 **1 小时转写**，累计使用，用完不自动恢复。AI 问答另有每日限制，以账号面板为准；转写额度用完后，录音仍可保存，已有内容仍可回放、下载和提问。课堂保存 30 天，请及时下载重要资料。

## 快速开始

需要 **Node.js 24 或更新版本**及其自带的 npm，支持 Windows、macOS、Linux。

不熟悉部署时，可按[自行部署与AI协助](docs/自行部署与AI协助.md)让AI带你完成。先在自己的电脑运行即可；云端API费用由自己的账号承担，体验站账号和课堂不会自动迁移。

首次注册需要验证邮箱。运行 `npm run setup` 后，在自己电脑的 `.env` 填写 `SMTP_HOST`、`SMTP_PORT`、`SMTP_USER`、`SMTP_PASS`，再启动。可使用邮箱服务商提供的 SMTP 授权码；详见[邮件配置步骤](docs/自行部署与AI协助.md#配置注册邮件)。密码和授权码只填在本机配置里。公网自部署还需填写自己的运营者、联系邮箱、存储地域和访问服务信息（`PUBLIC_*`），不要沿用示例中的维护者信息。

```sh
git clone https://github.com/MrRoam/jiwen.git
cd jiwen
npm ci
npm run setup
npm run dev
```

打开 **http://localhost:4317**，点击“开始使用”，填写邮箱、获取邮件验证码并设置密码即可注册，无需邀请码，不限注册人数。注册前需配置 SMTP 邮件服务。新实例首个邮箱账号是管理员。

**登录 → 点击侧栏底部账号 →「API 配置」→ 填写自己的密钥 → 保存配置 → 测试连接 → 开始录音。**

- 转写建议阿里云百炼，问答建议 Qwen。默认地址和模型已填好；使用百炼时可以复用一个 Key。
- 两项服务都允许自填密钥、地址和模型，兼容要求见 [API 配置](docs/API配置.md)。
- 不填写 API Key 也能启动、注册、录音保存和回放；真实转写及问答需要连接服务。
- 页面保存立即生效，无需重启。密钥只保存在服务器私有数据目录，不回显，不包含在仓库中。

Windows 也可双击 `启动.cmd`：安装依赖、构建并自动打开浏览器。使用期间保留终端；关闭窗口或按 Ctrl+C 停止服务。

`npm run setup` 只创建缺失的 `.env`，已有配置绝不覆盖。接口建议和示例不是附赠的 API 额度，云端调用的权限、余额与费用由你自己的账号承担。

## 使用方式

1. 开始录音并允许麦克风权限，界面显示收音状态及实时转写。
2. 直接输入问题，或选择一段讲解“就此提问”；可添加多处引用。
3. HELP 提供对老师最新问题的流式短答，可继续追问。
4. 每个对话使用独立的课堂背景快照，追问沿用该快照，不混入其他对话或后续课堂内容。
5. 暂停保存后回放，可拖动、倍速播放，点击转写时间跳到对应位置。

录音保存与转写独立。转写失败时仍会保存录音，可重连处理之后的音频；启用本机补转写服务时，缺失文字会在录音保存后尝试补齐；未启用时不能保证补齐，可查看录音下方的补转写状态。音频分段先保存在浏览器 IndexedDB，再顺序上传，重试去重，恢复网络后可补传。

“恢复上传”会分别补传并保存此账号在当前浏览器缓存的录音，一条录音失败不会阻断其他录音。正在其他页面录制的内容需要先停止录音，才能生成完整回放。服务器在生成回放后保留原始分段，支持迟到补传；旧版本已删除原始分段的录音仍可保存补传内容和已有回放，但原始内容缺失时无法合并完整回放。

## 配置入口

侧栏底部的账号入口可打开设置或修改密码。管理员控制台使用独立的本机入口：Windows 双击根目录的 **打开控制台.cmd**，或运行 `npm run console`，也可直接打开 **http://127.0.0.1:4319**。本机直接打开，无需账号或密码，即问页面不提供控制台入口；公网应用不提供控制台页面或管理接口。控制台仅监听本机回环地址，端口可通过 `.env` 中的 `CONSOLE_PORT` 修改，设为 `0` 可禁用。Docker 内该地址属于容器，不向宿主机或公网发布控制台端口。

控制台显示在线人数、录音与处理任务、近一小时在线趋势、全站每日额度和存储用量。数据每 5 秒更新；在线人数按账号去重，失效连接最迟在两轮心跳（约 60 秒）内移出。趋势从本次服务启动后开始积累。每日额度按现有规则在北京时间 08:00 重置；存储每 30 秒重新统计。服务的“已配置”表示具备配置，连接是否可用仍需单独检测。

概览顶部显示今日 API 成本合计、云端转写与 AI 问答分项，以及费用占比。按实际转发时长、供应商回报的 Token 和已核对的官方标准单价估算，免费问答及本机转写计零云 API 费用；赠送额度、优惠和本机资源开销不计入。当前自动计价支持北京地域的 Fun-ASR 实时转写、Qwen3.7-Flash 及 OpenRouter 免费路由；缺少来源、Token 或单价的旧记录标为未计价，不显示虚假的零成本。展开“计价说明”可查看单价和官方来源。统计日同样在北京时间 08:00 切换。

成本在服务后台持续记录，关闭控制台不会停止统计；重启、删除课堂或账号不会扣回已产生的成本。匿名计费记录与其他用量记录一起保留 90 天。这里展示本应用的 API 标准价估算，实际支付金额以供应商账单为准。

控制台可确认重启应用：存在录音、待恢复录音、保存、回放、问答、检测或后台处理任务时拒绝重启。使用 `npm start`、`npm run dev`、Docker 或新版内测脚本启动时默认启用；直接运行 `server/index.js` 时需显式设置 `CONSOLE_PORT`，且只提供监控。重启保留已保存的数据和额度，近一小时在线趋势重新积累；不会重启公网隧道或本地 Python 转写服务。已运行的旧实例需要在空闲时重新启动，才能加载独立控制台与新的启动管理进程。

自部署实例的管理员还能打开 **API 配置**，设置内也有同名入口；服务未配置时课堂页面提供“配置转写和问答”按钮。普通账号不显示配置入口；内测试用启动脚本关闭页面 API 配置，由维护者在服务器端管理，管理员控制台不受该开关影响。

| 内容 | 说明 |
| --- | --- |
| 页面配置 | 转写和问答的密钥、服务地址、模型、连接测试；仅管理员可修改 |
| 服务器 `.env` | 端口、监听地址、管理员邮箱、额度、邮件与可选功能 |
| `data/` | 私有 API 配置、SQLite 数据库、课堂录音 |

页面保存到 `data/service-config.json`，字段优先于 `.env`，重启后保留。未保存的字段使用环境变量或默认值。有人正在录音、保存、回答或测试时不允许修改接口配置。

API Key、数据目录、数据库、证书和日志都不应提交到 Git。仓库 `.env.example` 的密钥全部为空，服务器也不会把完整密钥发送到浏览器。

## 已知限制与验证

- 服务端单实例运行，SQLite 和录音存本地磁盘，需自行备份；不要并行启动使用同一数据库的服务。
- 浏览器退出后不会继续录音。手机锁屏、来电和切后台可能中断采集，使用时保持页面在前台。
- 断网时不要清除浏览器网站数据，尚未上传的分段只能在原设备、原浏览器及原账号恢复。
- 本地和模拟接口测试不代表你的密钥、实际麦克风或公网链路已验证。请分别测试连接并进行一次真实录音。
- 页面 API 配置不等于模型厂商管理台；程序内的账号额度不会修改云厂商账单。

测试使用临时数据库、模拟服务及合成音频，不使用真实密钥。覆盖账号隔离、邮箱验证注册、API 配置权限与持久化、独立上下文、HELP、录音顺序上传/去重、恢复和音频回放等行为。

运行完整测试前先执行 `npm run build`，再执行 `npm test`；控制台生产页面测试需要构建产物。

## 公测数据与本地GPU转写

支持政策查看、账号数据导出和注销；默认每账号 500 MiB 存储、全站 100 GiB，课堂从最后成功上传音频起保存 30 天。供应商信息按实例实际配置显示。本地模型的安装与可选补转写见[本地转写说明](docs/本地转写.md)。转写默认最多接入 50 路，新云端任务每秒最多启动 15 个；这些是程序限制，不代表任意服务器都已验证能承载 50 路完整课堂。请在自己的设备与服务配置下完成真实录音验收。

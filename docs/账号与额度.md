# 账号与额度

本地和正式部署均用邮箱、注册验证码和密码注册，无需邀请码，不限注册人数。邮箱验证通过后才创建账号并发放体验额度；已有账号继续用邮箱和密码登录。旧 `.env` 中的 `MAX_USERS` 不再生效。密码为 8～128 位，服务端保存加盐哈希；课堂、录音和对话按账号隔离。

新实例首个邮箱账号自动成为实例管理员，只有管理员能修改转写和问答 API。已有数据库会保留账号和课堂，将最早创建的邮箱账号作为管理员。服务器可通过 `ADMIN_EMAIL` 指定管理员邮箱；变更后重启生效。旧邀请数据保留在原数据库中，但不参与任何注册判断。

公开网站前先在受控访问环境注册管理员，再向其他人分享。注册必须验证邮箱所有权，需配置 SMTP。验证码为 6 位数字，10 分钟有效，每邮箱每分钟最多发送一次、每小时最多 5 次，输错 5 次后需重新获取。注册验证码与找回密码验证码独立，重发替换旧码；邮件发送失败可立即重试，仍受小时发送限制。未配置邮件服务时无法新注册，已有账号仍可登录；找回密码入口仅在邮件服务已配置时显示。中英文界面均可使用。

## 默认限制

公开体验站使用 `ASR_QUOTA_MODE=trial`：每个新账号一次性获得 **3,600 秒（1 小时）转写额度**，累计使用，不按日或月恢复。已有账号在首次启用该规则时也获得新的 1 小时；刷新、重连、重启不会重新赠送。管理员账号执行相同限制。新注册验证邮箱所有权，但按账号计量，不承诺阻止同一人使用多个邮箱领取。

自部署默认使用 `ASR_QUOTA_MODE=monthly`，额度由自己的管理员设置。自己的云 API 和服务器费用由自己承担，体验站账号及课堂不会自动迁移。

| 环境变量 | 默认值 | 含义 |
| --- | --- | --- |
| `ASR_QUOTA_MODE` | monthly | 自部署按月额度；trial 为一次性 1 小时，忽略个人月度参数 |
| `MONTHLY_AUDIO_SECONDS` | 36000 | 每账号每月转写秒数；不限制录音累计时长 |
| `GLOBAL_DAILY_ASR_SECONDS` | 360000 | 全站共享的每日转写秒数，即 100 小时/日 |
| `MAX_ASR_CONCURRENCY` | 50 | 转写接入上限，包含等待启动的连接 |
| `ASR_STARTS_PER_SECOND` | 15 | 云端新任务匀速启动，不限制已启动任务持续发送音频 |
| `DAILY_QUESTIONS` | 20 | 每账号每日模型调用次数 |
| `GLOBAL_DAILY_QUESTIONS` | 800 | 实例每日问答次数 |
| `GLOBAL_REQUESTS_PER_MINUTE` | 18 | 实例滚动 60 秒内的问答次数 |

在 `.env` 修改并重启。已有 `.env` 的自定义值会保留，不会被初始化覆盖。

问答次数包括普通问题、追问、HELP、连接测试、已发起但失败的模型请求。被本地额度拒绝的请求不触发模型。全站额度由所有账号共享，删除课堂或重启不会返还次数。每日额度按 UTC 日期重置，即北京时间 08:00；这些限制不等于云厂商的剩余额度或费用上限。

侧栏账号面板显示 AI 问答剩余百分比、进度条及重置时间。体验站转写显示剩余分钟和“一次性额度，不会重置”，并提供部署教程与可复制给 AI 的提示；自部署月度模式显示转写剩余百分比和重置时间。默认每日 20 次问答时，每次正常模型请求约消耗 5%；追问、连接测试和已发出的失败请求也消耗额度，备用模型调用单独计数。问答每日北京时间 08:00 重置；月度转写于每月 1 日北京时间 08:00 重置。读取失败可重试，不显示满额。

额度下方的小铃铛用于表达对付费选项的期待，点击不会扣费或增加额度。每个账号计入一次期待人数，连续敲击只播放动效；记录保存到服务器，换设备仍可读取。个人数据副本包含这条记录，注销账号时清除。组件支持键盘操作，并遵循系统的减少动态效果设置。

转写在每包音频发送前检查个人额度及全站日额度；本地实时、远程实时及后台补写共用额度，已计量的录音位置不重复扣。体验模式使用独立累计表，不会因清理 90 天用量明细而返还；月度模式使用 `asr_usage` 按 UTC 自然月统计。只有成功交给转写服务的音频才扣额度；未就绪或未发送的包不扣。每条连接按整秒向上预留，结合上游累计时长回报核对，不返还已发送音频。删除课堂、重连和重启不能返还额度。个人或全站额度用完会停止转写及自动重试，录音仍可上传、保存、回放和下载，已有文字仍可提问（受问答限制）。全站每日额度于北京时间 08:00 重置，不恢复个人一次性额度。录音独立受存储容量及单段最多 2 小时限制。

全站默认共享 100 小时转写/日，没有额外的转写月总量或人民币金额硬上限。后台补写需单独启用本地 Python 服务，最多一个任务，不处理尚在录制或保存的同一条录音。问答默认每账号 20 次/日、全站 800 次/日；这些数值不是同时在线人数上限。全站限额耗尽时，个人有余额也需等待全站恢复。OpenRouter 的本地预留计数不包含其他应用使用同一云账号的请求。

# 账号与额度

本地和正式部署均直接用邮箱、密码注册，无需邀请码。密码为 8～128 位，服务端保存加盐哈希；课堂、录音和对话按账号隔离。

新实例首个邮箱账号自动成为实例管理员，只有管理员能修改转写和问答 API。已有数据库会保留账号和课堂，将最早创建的邮箱账号作为管理员。服务器可通过 `ADMIN_EMAIL` 指定管理员邮箱；变更后重启生效。旧邀请数据保留在原数据库中，但不参与任何注册判断。

公开网站前先在受控访问环境注册管理员，再向其他人分享。注册邮箱当前不做所有权验证。配置 SMTP 后支持邮件找回密码，未配置时隐藏该入口。中英文界面均可使用。

## 默认限制

| 环境变量 | 默认值 | 含义 |
| --- | --- | --- |
| `MAX_USERS` | 100 | 有邮箱账号的最大数量；满额仍可登录 |
| `MONTHLY_AUDIO_SECONDS` | 36000 | 每账号每月录音/转写秒数 |
| `DAILY_QUESTIONS` | 120 | 每账号每日问答次数 |
| `GLOBAL_DAILY_QUESTIONS` | 800 | 实例每日问答次数 |
| `GLOBAL_REQUESTS_PER_MINUTE` | 18 | 实例滚动 60 秒内的问答次数 |

在 `.env` 修改并重启。已有 `.env` 的自定义值会保留，不会被初始化覆盖。

问答次数包括普通问题、追问、HELP、连接测试、已发起但失败的模型请求。被本地额度拒绝的请求不触发模型。全站额度由所有账号共享，删除课堂或重启不会返还次数。每日额度按 UTC 日期重置，即北京时间 08:00；这些限制不等于云厂商的剩余额度或费用上限。

设置中的账号页面可以查看今日问答余量。录音使用量和问答计数保存在本地 SQLite。OpenRouter 的本地预留计数不包含其他应用使用同一云账号的请求。

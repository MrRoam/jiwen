# 转写和问答配置

打开「设置 → 转写与问答」。填写自己的服务密钥，保存后分别测试转写和问答。

密钥保存在自己的电脑上，不完整回显。录音、保存、回答或连接测试期间，请先结束当前操作，再修改配置。

## 转写

选择「云端实时转写」，填写密钥。默认配置为：

| 项目 | 默认值 |
| --- | --- |
| 服务地址 | `wss://dashscope.aliyuncs.com/api-ws/v1/inference` |
| 模型 | `fun-asr-realtime` |

默认接口使用阿里云百炼协议。密钥、模型权限和服务地域需匹配。其他地域使用服务商提供的对应地址。

自填接口需支持百炼实时转写的任务和结果事件协议，接收 16 kHz 单声道 PCM。不能仅替换地址就接入不同协议的服务。

连接测试通过后，再录一段短音频确认实际识别。测试连接不会检查麦克风。

选择本机模型时，先按[本机转写模型](本地转写.md)准备模型，再在页面选择「本机 faster-whisper」。

## 问答

默认配置为：

| 项目 | 默认值 |
| --- | --- |
| 接口基础地址 | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| 模型 | `qwen3.7-flash` |

填写独立密钥，或在使用百炼时选择复用转写密钥。更换供应商时填写对应的密钥。

兼容接口需支持 Bearer 鉴权、`messages` 请求和流式 `/chat/completions` 响应。基础地址不重复填写 `/chat/completions`；正文需通过 `choices[0].delta.content` 返回。

点击「测试连接」会发出一次真实问答请求，可能计费。云端费用和可用量以自己的服务账号为准，即问个人使用不另设每日或每月额度。

可选的优先与备用服务见[问答路由](OpenRouter优先路由.md)。

## 保存与排错

保存成功表示配置生效，连接测试通过表示服务响应正常。还需用实际录音确认转写和回放。

空密钥输入会保留原值；使用「清除密钥」才能删除。密钥保存在 `data/personal/service-config.json`，不要公开这个文件。

转写失败时，录音仍会保存。检查麦克风权限、输入设备及连接错误；问答可用不代表转写也已连接。

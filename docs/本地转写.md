# 本机转写模型

这是可选方式。使用云端转写时，不需要安装本机模型。

选择本机模型后，转写音频在自己的电脑上处理。问答仍使用自己配置的问答服务。

## Windows

需要可用的 Python，安装脚本会创建独立环境并安装依赖。模型下载需要网络，运行时会占用本机资源。

在项目目录执行：

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File scripts/setup-local-asr.ps1 -Engine whisper -Device cpu
.\.venv-asr\Scripts\python server/local_asr.py --engine whisper --model small --device cpu --compute int8
```

保持这个模型进程开启。在即问中打开「设置 → 转写与问答」，选择「本机 faster-whisper」。默认地址为 `http://127.0.0.1:4318`，模型名称为 `small`。保存后测试连接，再录一段短音频确认文字。

macOS 和 Linux 可创建独立 Python 环境，按 `server/requirements-local-asr.txt` 安装依赖，再运行同一个 `server/local_asr.py`。模型名称和设备参数应与实际运行的模型匹配。

若希望在录音保存后补齐缺失文字，可在本机 `.env` 设置 `LOCAL_ASR_RECOVERY=true`，然后重新启动即问。模型进程需保持运行。未启用时，转写断线期间的文字不能保证补齐。

# 本地转写（可选）

本地 faster-whisper 服务运行在应用服务器所在的机器。音频不发送到云端转写服务；问答仍按已配置的接口运行。默认不安装 Python 依赖，不自动下载模型。

在项目目录创建独立 Python 环境：

```sh
python -m venv .venv-asr
```

Windows：

```powershell
.\.venv-asr\Scripts\python -m pip install -r server/requirements-local-asr.txt
.\.venv-asr\Scripts\python server/local_asr.py
```

macOS/Linux：

```sh
.venv-asr/bin/python -m pip install -r server/requirements-local-asr.txt
.venv-asr/bin/python server/local_asr.py
```

首次运行默认下载 `small` 模型，等待服务显示已启动。然后进入侧栏“API 配置”，转写方式选择“本机 faster-whisper”，地址为 `http://127.0.0.1:4318`，模型为 `small`，保存并测试连接。

模型、设备和计算类型通过 Python 进程的 `LOCAL_ASR_MODEL`、`LOCAL_ASR_DEVICE`、`LOCAL_ASR_COMPUTE` 环境变量设置。Python 服务不自动读取 `.env`；页面中的模型名称是应用显示配置，修改它不会替 Python 服务下载或切换模型，需要同时修改并重启 Python 服务。

录音约每 10 秒提交一批，暂停时提交尾段；显示延迟包含采集时间和本机推理时间。超过两分钟缓冲会报错，录音仍保存。测试会实际处理一秒静音；CPU 性能、模型大小、网络下载会影响首次启动和速度。

Docker Compose 默认不包含此 Python 服务。依赖和硬件说明参见 [faster-whisper](https://github.com/SYSTRAN/faster-whisper)。

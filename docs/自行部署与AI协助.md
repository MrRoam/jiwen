# 在自己的电脑使用即问

启动即问，配置自己的转写和问答服务，即可开始使用。无需注册，也无需准备发信邮箱。

## 安装与启动

1. 安装 Node.js 24 或更新版本，保留安装程序附带的 npm。
2. 下载并解压[即问源码](https://github.com/MrRoam/jiwen/archive/refs/heads/main.zip)。Windows 双击 `启动.cmd`。macOS 和 Linux 在项目目录执行 `npm ci`，再执行 `npm run dev`。
3. 打开 `http://localhost:4317`。点击「设置 → 转写与问答」，填写自己的服务密钥，保存后分别测试连接。
4. 录音约 30 秒，暂停并等待保存。确认文字、提问和回放均可用。

运行期间保持启动终端开启，按 Ctrl+C 停止应用。密钥在页面填写，不需要先编辑配置文件。

转写与问答可以使用不同服务。支持的接口和填写方法见[配置说明](API配置.md)。云端服务按自己的账号计费；没有服务密钥时，仍可录音、保存和回放。

## 资料在哪里

个人资料默认保存在项目目录的 `data/personal/`，不会按期限自动删除。可在「设置 → 我的资料」下载文字、对话和录音；在课堂列表删除不需要的课堂。

停止应用后，完整复制 `data/personal/` 可保留数据库、录音和服务配置。这个目录包含密钥和个人资料，请保存到自己的受控设备。

旧版本若要求邮箱注册，原资料位于原数据目录。新版使用独立目录，不会覆盖原件。暂不提供自动合并；先在旧版本下载所需录音和数据副本。体验站资料也不会自动迁移到本机。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 打不开页面 | 检查启动终端的错误，并确认应用仍在运行 |
| 安装依赖失败 | 安装会下载音频处理工具，检查网络后按具体错误处理 |
| 可以录音但没有文字 | 检查转写服务配置、连接测试和麦克风收音状态 |
| 模型连接失败 | 核对服务地址、模型权限和余额，使用脱敏错误定位 |
| 提示存在旧账号资料 | 保留原目录，按上文处理旧资料，不清空数据库 |

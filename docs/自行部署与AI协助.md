# 自行部署即问，可以让AI带你完成

源码免费。你可以先在自己的电脑运行，不必购买服务器。转写和问答需要你自己的API服务，云端费用由你承担；服务器或本机运行也会消耗资源。

自行部署会创建独立实例。体验站账号、录音、转写和对话不会自动出现在新实例中。原资料可从体验站“账号 → 数据与反馈”下载，当前没有一键导入到新实例的功能。

公开源码：[GitHub · MrRoam/jiwen](https://github.com/MrRoam/jiwen)。以实际下载版本的 README 和命令为准。

## 最短路径：先在自己的电脑运行

1. 准备Git、Node.js 24或更新版本及其附带的npm。不熟悉安装时，把下面的提示交给AI。
2. 按[README快速开始](../README.md#快速开始)安装依赖，运行 `npm run setup` 创建本机配置。
3. 按下文配置 SMTP 邮件服务，再启动应用，打开 `http://localhost:4317`。通过邮箱验证码注册自己的账号，新实例首个邮箱账号是管理员。点击侧栏底部账号，进入“API 配置”，填写自己的转写和问答服务配置。邮件授权码和 API 密钥只填入自己的实例，不贴给AI。
4. 保存配置，分别测试转写和问答，再录一段30秒的音频，暂停保存，检查转写、提问和回放。启动成功或“已配置”不能代替这一步。

运行期间保持服务进程开启。浏览器需要麦克风权限，手机锁屏或切后台可能中断录音。

想在手机或其他设备访问，再按[服务器部署说明](../deploy/README.md)配置HTTPS和访问地址。不要直接把手机访问的HTTP局域网地址当作可用录音入口，也不要在初次体验前先购买服务器。

体验站每个新账号一次性赠送 1 小时转写，用完不自动恢复。自部署默认使用 `ASR_QUOTA_MODE=monthly`，管理员可在 `.env` 中设置 `MONTHLY_AUDIO_SECONDS`，不会固定继承体验站的 1 小时限制。程序额度不是云厂商的赠送余额，详见[账号与额度](账号与额度.md)。

## 配置注册邮件

注册需要接收验证码。SMTP 是应用通过你的邮箱服务商发送邮件的方式，不是转写或问答 API。

1. 在邮箱服务商的设置中启用 SMTP，获取授权码。QQ 邮箱可使用示例中的 `smtp.qq.com` 和 `465`；其他邮箱按服务商提供的地址与端口填写。
2. 在项目根目录的 `.env` 填写 `SMTP_HOST`（服务地址）、`SMTP_PORT`（端口）、`SMTP_USER`（发信邮箱）和 `SMTP_PASS`（授权码）。可选 `MAIL_FROM` 必须是该邮箱服务允许的发件人。
3. 保存后重启即问，点击注册页“获取验证码”，确认收到邮件，再用验证码注册。仅填写配置不表示邮件发送已验证。

授权码不要发给 AI，也不要提交到 GitHub。未配置邮件时无法新注册，已有账号仍能登录。收不到邮件时检查垃圾邮件、地址、端口、授权码及服务商发信限制，将脱敏错误交给 AI 定位。

## 复制下面这段给AI

```text
请协助我部署开源项目即问：
https://github.com/MrRoam/jiwen

我是普通用户。先问我用Windows、macOS还是Linux，以及是否只在自己的电脑使用。
先阅读实际下载版本的README、package.json、.env.example和deploy/README.md，按该版本操作，不猜测命令或把尚未发布的功能当作已实现。

优先让我在自己的电脑运行，不先要求购买服务器、域名或GPU。
如果你能操作我的电脑，请检查Git、Node.js和npm；项目需要Node.js 24或更新版本。
如果你只能对话，请分步骤给我适合当前系统的命令，每一步说明看到什么结果才算成功。
下载仓库、按锁文件安装依赖、创建缺失的本机配置。
注册需要邮件验证码。先带我在.env填写自己的SMTP服务地址、端口、发信邮箱和授权码，再启动服务，并确认能够收到注册邮件。
不要覆盖已有.env，不删除data、数据库或录音，不并行启动使用同一端口或数据库的服务。

启动后，带我打开页面、注册管理员，并找到“侧栏底部账号 → API配置”。
解释转写和问答各需要什么服务、哪些费用由我承担，以及在哪里配置自己的用量限制。
不要索取或回显API密钥、密码、邮件授权码或.env全文；由我在自己的实例里填写。

完成连接测试，再让我做30秒真实录音、暂停保存、查看转写、提问和回放。
如果出错，依据具体错误定位原因，不反复重装或清空数据。
说明哪些已验证，哪些还没验证；只在我需要手机或远程访问时继续配置HTTPS或服务器。
提醒我，体验站已有资料不会自动迁移，新实例需要单独注册。
```

## 常见卡点

| 现象 | 下一步 |
| --- | --- |
| 打不开本机页面 | 看启动终端是否报错、服务进程是否仍在运行，确认实际监听端口 |
| 能录音但没有文字 | 检查转写配置、连接测试和账号额度；问答密钥不一定等于转写服务已可用 |
| 注册后找不到API配置 | 确认这是自己的实例且当前账号为管理员；体验站普通账号不能配置 |
| 手机能打开但不能录音 | 检查HTTPS、浏览器麦克风权限，并保持页面前台 |
| 云服务连接失败 | 将脱敏后的错误交给AI定位，不发送密钥或含个人信息的完整日志 |

本文仅是操作指南，没有替你启动服务、购买云资源或验证你的真实设备。

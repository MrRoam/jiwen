## 开发与检查

前端使用 React + Vite，后端使用 Express + WebSocket + SQLite。音频转码使用 FFmpeg。课堂上下文的行为见[课堂上下文与时间轴](课堂上下文与时间轴.md)，项目协作要求见 [AGENTS.md](../AGENTS.md)。

| 任务 | 命令 |
| --- | --- |
| 按锁文件安装依赖 | `npm ci` |
| 创建缺失的本机配置 | `npm run setup` |
| 启动开发服务 | `npm run dev` |
| 构建前端与控制台 | `npm run build` |
| 启动构建后的应用 | `npm start` |
| 运行全部 JavaScript 测试 | `npm test` |
| 检查 Git 跟踪文件中的私有内容 | `npm run check:release` |

先执行 `npm run build`，再执行 `npm test`。控制台测试需要构建产物。测试使用临时数据库、模拟服务和合成音频；真实麦克风、云服务和公网访问需单独验证。

依赖安装会下载 FFmpeg。下载失败时检查网络、代理和证书。已有 FFmpeg 时，可在安装和运行环境设置 `FFMPEG_BIN`，值为程序的绝对路径。

发布检查只扫描当前 Git 跟踪文件，不能代替历史记录、图片和其他格式的检查。不要提交 `.env`、`data/`、数据库、录音、密钥、证书、备份或日志。

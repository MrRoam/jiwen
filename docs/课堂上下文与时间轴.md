# 课堂上下文与时间轴

每堂课保留多个独立对话。普通新问题关联开始输入时的课堂位置；选文优先关联原句，回放提问使用回放位置。没有转写时使用录音计时。

首次发送时取关联位置前 3 分钟、后最多 30 秒内已经收到的文字，不等待未来内容。背景最多约 12000 字，显式引用优先、再保留最近的原句，并恢复课堂顺序。未定稿文字会标记，之后的识别修正不会改变已有对话快照。

尚为空且未真正用于回答的背景可以在之后提问时补取该位置的转写；一旦请求模型则冻结。追问发送固定课堂背景、当前对话历史和问题，失败的半截回答不作为可靠历史，不共享其他对话或后来课堂内容。

HELP 根据最近课堂内容快速回答当前问题，并建立独立对话和快照。继续追问沿用 HELP 的固定背景。

浏览器发送音频采集位置，服务端通过 AudioTimeline 映射识别时间，减少重新连接和采集暂停导致的时间偏差。原始识别句子分别保存；界面只把相邻短句合并展示，不改变句子 ID、时间戳或快照。

核心逻辑见 `server/context.js`、`server/audio-timeline.js`、`server/help.js`，验证见对应测试。

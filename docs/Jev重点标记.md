# Jev 重点标记

Jev 判断课堂原句是否包含值得学生复习回看的具体教学内容；判断为“是”的原句显示淡黄色高光（`#fff0ac`），其余保持原样。不判断事实正确性，不给老师本人评级，不显示分数或自动生成解释。

## 配置与使用

默认 `JEV_ENABLED=false`，隐藏重点与提问识别入口且不调用服务。需要启用时，在服务器 `.env` 设置 `JEV_ENABLED=true` 并填写 `TYPESAFE_API_KEY`，重启后进入“设置 → 课堂功能 → 重点与提问识别 → 检测”。页面“已配置”只表示有密钥；只有实际调用成功才表示接口可用。密钥不放入浏览器、日志或 Git。

可选配置及默认值：

```dotenv
TYPESAFE_API_KEY=
JEV_MODEL=jev-latest
JEV_API_URL=https://api.typesafe.ai/v1/systemone
JEV_DAILY_REQUESTS=1200
JEV_GLOBAL_DAILY_REQUESTS=6000
TEACHER_QUESTION_DAILY_REQUESTS=200
TEACHER_QUESTION_GLOBAL_DAILY_REQUESTS=1000
```

课堂提问识别也使用 Jev，但独立于“重点标记”开关和判断队列。它只对定稿转写中的候选问句发起判断：明确任务等待约 3 秒，其他疑问句最多再等约 2.5 秒收集后续讲解；下一句提前定稿时提前判断。同一请求分别判断是否留给学生回答、是否已由讲述者自答、是否只是课堂确认。只显示明确通过的问句；失败或额度用尽时保持原文，不回退到关键词标记。提问识别调用次数有独立额度，录音与问答不受影响。

每堂课默认关闭，标题旁的“重点标记”开关保存到服务器。新课堂可在录音前开启，创建课堂时一并保存。开启后自动处理新的定稿句子，不自动补查历史；使用“分析已有内容”补查遗漏、取消和失败的片段。已完成结果不会重复调用。

关闭会停止排队任务、取消在途请求、立即隐藏染色，保留已完成结果。已发出的请求可能已经产生费用；重新开启不会自动补查关闭期间的内容。暂停录音后后台仍处理已排队任务，前端每 3 秒读取一次结果。未配置、接口失败或额度用尽不阻断录音、转写和问答。

## 判断与显示

使用官方 Noul 是/否题，输入为当前原句和附近课堂上下文；每个问题明确指定目标句子，不依赖 question ID 作为模型指令。问题只问原句是否包含值得学生复习回看的具体教学内容。知识、结论、因果解释、具体例子、方法步骤、纠错以及明确作业考试要求可判“是”；寒暄、填充、过渡、无新增内容的重复，以及残缺到无法确定内容的句子判“否”。必要的重复强调不因重复而自动判“否”。

Noul 返回“是”的概率，当前用 `0.5` 作为初始显示分界：不低于 `0.5` 时高亮原句，否则保持原样。它不是“重要程度”或正确率；分界尚需真实中文课堂样本校准。页面不显示概率，也不做分类、解释、整节课评分或低分变灰。

输入只来自转写，没有板书、课件、说话人身份或音频理解，可能误判。当前仍按识别服务的定稿句子判断，使用前文和等待期间收到的邻近句子理解短句；尚未实现跨句语义重分段或课程级去重。

原句定稿后等待约 8 秒，单次最多 8 句，全站队列同时只发一个分析请求。上下文选取前约 2 分钟及已收到的后约 15 秒，最多 60 句、6000 字。网络往返、队列、转写速度会增加延迟。

## 存储与失败处理

`importance_settings` 按课堂保存开关；`importance_results` 保存句子关联、原文及时间哈希、任务版本、Noul 结果、模型和判断标准版本；删除课堂或句子级联删除结果。旧评分列保留以兼容已有数据库，但不再用于页面；旧结果不会冒充新判断，已启用课堂可用“分析已有内容”重新判断。

关闭、删除或文本变更后，旧请求不能写回结果。进程重启将未完成任务重新排队，只处理仍启用的课堂。网络超时为 15 秒，429/5xx 自动重试一次，其他错误由用户手动重试。失败不会被当成“否”。

Jev 额度独立于问答额度，按每次 API 请求扣计，含测试、自动重试和失败调用。每天 UTC 00:00（北京时间 08:00）重置；重启、删除课堂不能返还额度。默认额度是调用次数上限，不是精确的金额预算。

主要文件：`server/importance.js`、`src/importance.jsx`、`src/importance.css`。API 为已登录且有课堂访问权限的 `GET/PATCH /api/lessons/:lessonId/importance` 和 `POST /api/lessons/:lessonId/importance/analyze`。

## 验证范围

自动化测试使用本地模拟服务，无真实密钥、无云端费用，覆盖开关、定稿触发、历史补查、去重、旧结果作废、关闭取消、账号隔离、接口格式、失败与限额、旧数据库迁移和高亮判断。

真实 Jev 联调及中文课堂判断质量仍需配置密钥后验证。官方资料：[快速入门](https://docs.typesafe.ai/introduction/quickstart)、[Noul](https://docs.typesafe.ai/primitives/noul)。

# 本机体验站维护（维护者使用）

本文维护当前体验站。普通自部署用户请使用 [本机部署与 AI 协助](../docs/自行部署与AI协助.md) 或 [服务器部署](README.md)，不需要安装维护者的公网隧道。

网站运行在维护者电脑，Cloudflare Tunnel 提供 HTTPS 入口。公开地址为 https://jiwen.yaojiaxu.com，指向本机 http://localhost:4317；账号和录音保存在原 data 目录。隧道由 Windows 的 cloudflared 服务运行，与应用进程分开。

## 体验规则

体验站仅供体验，当前不收费。每账号一次性获得 1 小时转写，用完不自动恢复；录音仍可保存、回放和下载，已有文字仍能提问（受每日问答限制）。启动脚本固定 ASR_QUOTA_MODE=trial 和 API_CONFIG_ENABLED=false，普通用户不能修改服务器的 API 配置。新注册需要邮箱验证码，应先配置 SMTP。

## 启动与更新

初次启动前，在 .env 填写自己的转写、问答和邮件服务配置，以及 TRIAL_PUBLIC_URL。Cloudflare 公共主机名应指向本机应用，隧道服务需已安装。参见 [Cloudflare 官方说明](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/)。

双击“启动内测.cmd”，或运行：

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File deploy/start-trial.ps1 -NoBrowser
```

脚本安装缺失依赖、构建前端、启动应用和按配置启用本地转写，再验证公网。关闭启动窗口不会停止后台服务。健康且已启用体验规则的现有实例会被复用；复用不代表已加载新代码。旧额度规则会明确拒绝复用。

更新前检查本机控制台 http://127.0.0.1:4319，确认没有录音、保存、回答、回放、待恢复录音或补转写任务。先备份，再在空闲时停止、重新构建启动，核对公网 /api/me 的 asrQuotaMode 为 trial。账号和录音保留，不清空 data。

双击“停止内测.cmd”停止此项目的应用及本地转写；Cloudflare 隧道保持运行，应用停机期间公网可能返回 502。

## 分享前验证

分别检查邮箱验证码注册与登录、连接测试、真实短录音与转写、暂停保存、回放、问答及账号隔离。手机访问必须使用 HTTPS，并保持页面前台；锁屏或切后台可能中断采集。本地模拟测试和已配置状态不能代替实际设备验证。

体验结束后，网站账号面板提供部署教程和可复制给 AI 的提示。自部署使用独立账号和资源，不自动迁移体验站资料，也不固定继承体验站的一次性额度。
